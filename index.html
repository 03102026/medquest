Como funciona

Cadastre primeiro os períodos, disciplinas, assuntos e provas na aba Cadastros. Depois eles aparecem automaticamente nos campos desta tela.

Rascunho

A questão fica guardada no banco mas não aparece para os alunos.

Publicada

A questão aparece na área de questões para alunos autenticados.

🌳 Estrutura do conteúdo

Organize em árvore: Instituição → Períodos → Módulos → Assuntos. Use os botões de cada linha para adicionar, editar, mover (▲▼), ocultar dos alunos (👁) ou excluir. O que você criar aparece para os alunos na hora.
